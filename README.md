# CodeAlpha Calculator

A responsive calculator built with HTML, CSS and JavaScript as part of my CodeAlpha Front-End Development Internship.

## Features
- Addition, subtraction, multiplication and division
- Clear and delete buttons
- Keyboard support
- Error handling (for example, division by zero)
- Responsive design

## Technologies
HTML, CSS, JavaScript

## How to run
Download the files and open `index.html` in your browser.
